# Criar, Manipular e Apresentar Dados Utilizando Estatística Descritiva

Repositório destinado à organização das atividades práticas e dos conhecimentos desenvolvidos durante o curso **Criar, Manipular e Apresentar Dados Utilizando Estatística Descritiva**, realizado pelo Senac.

## Objetivo

Desenvolver conhecimentos e habilidades relacionados à manipulação, análise e apresentação de dados, aplicando conceitos de estatística descritiva e utilizando ferramentas de programação, bancos de dados e visualização de informações.

## Tecnologias e Ferramentas

- **Python:** utilização das bibliotecas Pandas, Polars e SQLAlchemy para manipulação e integração de dados.
- **Visualização de Dados:** Matplotlib e Seaborn para criação de gráficos e representações visuais.
- **SQL:** consultas, manipulação e análise de dados em bancos relacionais.
- **MySQL Workbench:** gerenciamento e interação com bancos de dados MySQL.
- **Power BI:** construção de relatórios e dashboards para apresentação de informações.
- **Microsoft Excel:** organização, manipulação e análise de dados.

## Conhecimentos Desenvolvidos

- Estatística descritiva e análise exploratória de dados (EDA).
- Medidas de dispersão, incluindo variância.
- Identificação e análise de valores atípicos (*outliers*) utilizando IQR (Intervalo Interquartil).
- Distribuições de frequência e interpretação de histogramas.
- Manipulação, tratamento e organização de conjuntos de dados.
- Criação de visualizações e interpretação de resultados.
- Apresentação de informações por meio de relatórios e dashboards.
